4. Step by Step Project Creation
============================================================

Step 1: Create a Console Application

Create a new console application named:
EFCoreCodeFirstModuleWay

Example command:
dotnet new console -n EFCoreCodeFirstModuleWay

Step 2: Add EF Core Packages

Install Entity Framework Core tools:
dotnet add package Microsoft.EntityFrameworkCore.Tools

Install MySQL EF Core provider:
dotnet add package MySql.EntityFrameworkCore

Step 3: Create Model Folder

Create a folder named:
Model

This folder stores entity classes.

Step 4: Create Department Entity

Create file:
Model\Department.cs

Important properties:
DepartmentId
DepartmentName
Location
Employees

DepartmentId is the primary key.
Employees is a navigation property.

Step 5: Create Employee Entity

Create file:
Model\Employee.cs

Important properties:
empId
EmpName
Salary
email
DepartmentId
department

empId is the primary key.
DepartmentId is the foreign key.
department is the navigation property.

Step 6: Add Data Annotations

Common annotations used:
[Key]
[Required]
[StringLength]
[Range]
[EmailAddress]
[ForeignKey]

These annotations define validation rules and database mapping rules.

Step 7: Create Dal Folder

Create a folder named:
Dal

This folder stores database access logic.

Step 8: Create DbContext Class

Create file:
Dal\DBCon.cs

DBCon class inherits from DbContext.

Example:
public class DBCon : DbContext

Step 9: Add DbSet Properties

Inside DBCon class, add:
public DbSet<Employee> Employees { get; set; }
public DbSet<Department> Departments { get; set; }

DbSet represents a table in the database.

Step 10: Configure Database Connection

Override OnConfiguring method in DBCon.cs.

Use MySQL connection:
optionsBuilder.UseMySQL("Server = 127.0.0.1; Port = 1919; Database = EmpDB; User Id = root; Password = root;");

Step 11: Create Migration

Run migration command from project folder:
dotnet ef migrations add intial

This creates migration files inside the Migrations folder.

Step 12: Apply Migration to Database

Run:
dotnet ef database update

This creates database tables in MySQL based on entity classes.

Step 13: Verify Database

Open MySQL and check:
Database: EmpDB
Tables: Employees, Departments

7. Key Points to Remember
============================================================

1. Entity Framework Core is an ORM.
2. ORM means Object Relational Mapper.
3. EF Core maps C# classes to database tables.
4. Entity classes are stored in the Model folder.
5. DbContext manages database connection and entity tracking.
6. DbSet represents a database table.
7. Code First means we create C# classes first, then generate database tables.
8. Migrations are used to create or update database schema.
9. Data annotations are used for validation and table mapping.
10. [Key] defines primary key.
11. [Required] makes a field mandatory.
12. [StringLength] sets maximum string length.
13. [Range] sets minimum and maximum numeric values.
14. [EmailAddress] validates email format.
15. [ForeignKey] defines relationship between tables.
16. OnConfiguring is used to configure database provider and connection string.
17. UseMySQL tells EF Core to use MySQL database.
18. Navigation properties help access related data.
19. Migrations folder should not be deleted without understanding its purpose.
20. Always check connection string before running database update.

11. Viva Questions and Answers
============================================================

Q1. What is Entity Framework Core?
Ans. Entity Framework Core is an ORM framework for .NET. It allows developers to work with databases using C# classes instead of writing SQL queries directly.

Q2. What is ORM?
Ans. ORM means Object Relational Mapper. It maps objects in programming language to tables in a relational database.

Q3. What is Code First approach?
Ans. Code First approach means we create C# model classes first, then EF Core creates database tables from those classes using migrations.

Q4. What is DbContext?
Ans. DbContext is the main class in EF Core that manages database connection, entity objects, change tracking, and database operations.

Q5. What is DbSet?
Ans. DbSet represents a table in the database. For example, DbSet<Employee> represents the Employees table.

Q6. Which DbContext is used in this project?
Ans. This project uses DBCon class as the DbContext.

Q7. Which database is used in this project?
Ans. This project uses MySQL database.

Q8. Which provider is used for MySQL?
Ans. MySql.EntityFrameworkCore package is used as the MySQL provider.

Q9. What is the purpose of OnConfiguring method?
Ans. OnConfiguring is used to configure the database provider and connection string for DbContext.

Q10. What is a migration?
Ans. A migration is a file generated by EF Core that stores database schema changes based on model classes.

Q11. Why do we use dotnet ef database update?
Ans. This command applies pending migrations to the database and creates or updates tables.

Q12. What is a primary key?
Ans. A primary key uniquely identifies each record in a table.

Q13. Which property is primary key in Employee?
Ans. empId is the primary key in Employee.

Q14. Which property is primary key in Department?
Ans. DepartmentId is the primary key in Department.

Q15. What is a foreign key?
Ans. A foreign key is a column that creates a relationship between two tables.

Q16. Which property is foreign key in Employee?
Ans. DepartmentId is the foreign key in Employee.

Q17. What relationship exists between Department and Employee?
Ans. One-to-many relationship. One Department can have many Employees.

Q18. What is a navigation property?
Ans. A navigation property is used to access related data between entities.

Q19. What is the use of ICollection<Employee> in Department?
Ans. It represents multiple employees belonging to one department.

Q20. What is the use of [Key] annotation?
Ans. [Key] marks a property as the primary key.

Q21. What is the use of [Required] annotation?
Ans. [Required] makes the property mandatory and prevents null values.

Q22. What is the use of [StringLength(100)]?
Ans. It limits the maximum length of a string column to 100 characters.

Q23. What is the use of [Range(15000, 50000)]?
Ans. It restricts the Salary value between 15000 and 50000.

Q24. What is the use of [EmailAddress]?
Ans. It validates that the value follows email address format.

Q25. What is the use of [ForeignKey("Department")]?
Ans. It tells EF Core that the marked property is a foreign key for the related Department entity.

Q26. Why do we need package references in .csproj?
Ans. Package references add external libraries required by the project, such as EF Core tools and MySQL provider.

Q27. What is the purpose of the Migrations folder?
Ans. It stores migration files that define database schema changes.

Q28. Can we use EF Core without writing SQL queries?
Ans. Yes, EF Core allows us to perform database operations using C# objects and LINQ.

Q29. What command is used to add a migration?
Ans. dotnet ef migrations add MigrationName

Q30. What command is used to update the database?
Ans. dotnet ef database update

Q31. What happens if we change model classes after migration?
Ans. We need to add a new migration and run database update again.

Q32. Why is connection string important?
Ans. It tells the application where the database server is, which database to use, and login details.

Q33. What is the difference between model class and table?
Ans. A model class is a C# class. A table is a database object. EF Core maps model classes to tables.

Q34. What is the role of Program.cs?
Ans. Program.cs is the entry point of the console application.

Q35. What is change tracking in EF Core?
Ans. Change tracking means EF Core tracks changes made to entity objects and saves those changes to the database when SaveChanges is called.

Q36. What method is used to save changes in EF Core?
Ans. SaveChanges() is used to save changes to the database.

Q37. What is LINQ?
Ans. LINQ means Language Integrated Query. It is used to query collections and databases in C#.

Q38. What is the benefit of EF Core?
Ans. EF Core reduces manual SQL code, improves productivity, supports LINQ, and manages database schema through migrations.

Q39. What is the difference between Code First and Database First?
Ans. In Code First, we create C# classes first and generate database from them. In Database First, database already exists and classes are generated from it.

Q40. What should be checked if migration fails?
Ans. Check package installation, connection string, database server status, project build errors, and command folder location.

12. Short Summary for Exam
============================================================

This project demonstrates Entity Framework Core Code First approach using a .NET console application and MySQL database. It contains two entities: Employee and Department. DBCon is the DbContext class that connects the application to MySQL and exposes DbSet properties for Employees and Departments. Data annotations define primary keys, required fields, string length, salary range, email validation, and foreign key relationship. EF Core migrations are used to create database tables from the model classes.
